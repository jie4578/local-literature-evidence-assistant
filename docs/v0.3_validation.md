# v0.3.0-bilingual-corpus-preview 验证记录

本文件只记录已经完成的验证事实，用于 `0.3.0-bilingual-corpus-preview` 预览版评审。
不含本地绝对路径、用户名、私有 PDF 文件名、任务 ID、API Key 或请求头内容。

## 数据来源与性质

本文件中的验收数据来自**合成验收语料**，不是真实公开论文。

- 合成语料用于覆盖大批量身份模型、去重、暂停续跑、导出和字段映射等工程路径；
- **不得**把这些数据描述为“28 篇真实公开论文”；
- 真实论文的 Local Offline 验证规模目前仍然有限，仅达到 Limited Pilot 水平；
- 合成语料通过不等于真实论文生产可用。

### 结果说明

- 30 个输入对应 29 个唯一文档，说明存在 1 个重复输入（内容相同、文件名不同），被合并为同一 `document_id`；
- 29 个唯一文档中 28 个完成、1 个失败；失败文档保留错误状态；
- 28 篇成功文档全部生成独立论文报告，失败文档**没有**生成独立报告；
- 方法提取覆盖 28/28 全部成功文档；
- 方法与实验条件字段重叠为 0，即两者不再重复输出同一内容；
- Word 主报告最多展示 10 篇代表论文，且每篇都带选择原因记录；完整 28 篇成功文献仍保留在 Excel 和 JSON 中；
- Excel 保留完整成功文献，并额外提供输入映射（input → document 关系、内容指纹、状态、重复指向）和技术明细（选择策略、是否进入 Word、排名、分数、选择原因、独立报告路径）；
- 整个合成验收过程未发生网络、API 或 Provider 调用。

## 未覆盖或未通过的范围

- OCR：未实现，扫描件不受支持；
- 复杂表格识别：Limited，正文/表格标题/表格内容区分不稳定；
- DeepSeek 真实长论文：Experimental，尚未完整端到端通过；
- OpenAI、Ollama、Custom OpenAI-Compatible Endpoint：主要为 Mock 验证；
- AI 长论文分析：仍属于实验功能。

## 结论

工程路径（大批量身份模型、去重、暂停续跑、原子状态、导出、字段映射）在合成语料上通过。
真实论文的规模、跨领域和跨版式验证仍待补充，因此本版本为 **Preview**，不是稳定版或科研生产级版本。
