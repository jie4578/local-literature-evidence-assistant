# v0.4 Local Embedding Backend

## Implemented

- optional local `SentenceTransformer` encoder;
- local-directory-only model loading with `local_files_only=True` and `trust_remote_code=False`;
- batch-scoped SQLite embedding cache;
- text-hash invalidation and model fingerprint isolation;
- cosine semantic retrieval with source, section and current-batch filtering;
- integration with the existing `HybridRetriever` and RRF layer.

The default application remains Local Offline lexical retrieval. The optional dependency is listed in `requirements-semantic.txt`; it is not installed by the normal setup and no model is downloaded automatically.

## Not yet validated

- real model quality;
- biomedical retrieval quality;
- production-scale vector search;
- UI hybrid mode.

Phase 9C2 uses a deterministic test encoder for architecture validation. This is not a real-model quality benchmark.
